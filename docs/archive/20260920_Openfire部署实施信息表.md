## 二、对接认证信息

| 项 | 值 |
|---|---|
| 认证方式 | HTTP Basic Auth（请求头 `Authorization: Basic <base64>`，即 `curl -u`） |
| 用户名 | `admin` |
| 密码 | 见 `backend/.env` 的 `OPENFIRE_ADMIN_PASSWORD`（`<REDACTED>`，不写文档） |
| 后端环境变量 | `OPENFIRE_ADMIN_URL` / `OPENFIRE_ADMIN_USERNAME` / `OPENFIRE_ADMIN_PASSWORD` / `OPENFIRE_XMPP_DOMAIN` |

> REST API 插件需 3 个开关（已在部署时配好，缺一会 302/401）：
> `plugin.restapi.enabled=true`、`adminConsole.access.allow-wildcards-in-excludes=true`、`plugin.restapi.httpAuth=basic`

## 三、账号同步 API 清单

> 完整前缀：`/plugins/restapi/v1`（下表省略前缀）

| # | 方法 + 路径 | 用途 | 平台触发时机 |
|---|---|---|---|
| 1 | `POST /users` | 创建 IM 账号 | 平台建新用户 |
| 2 | `GET /users/{username}` | 查询账号是否存在 | 校验 / 对账 |
| 3 | `PUT /users/{username}` | 改密码 / 改姓名邮箱 | 改密、重置密码、改资料 |
| 4 | `DELETE /users/{username}` | 删除账号 | 用户离职 / 停用 |
| 5 | `POST /users/{username}/roster` | 加联系人（通讯录） | 建双向通讯录 |
| 6 | `GET /users/{username}/roster` | 查联系人 | 对账 / 排障 |
| 7 | `GET /sessions` | 查在线会话 | 排障 / 监控（可选） |

**认证示例**（所有接口都要带 basic auth）：

```bash
curl -u "admin:<ADMIN_PWD>" http://127.0.0.1:19090/plugins/restapi/v1/users
```

## 四、账号同步规则（平台事件 → 调用的接口）

| 平台事件 | 调用接口 | 说明 |
|---|---|---|
| 创建用户 | `POST /users` | 同步用户名（**全小写无空格**）+ 姓名 + 邮箱 + 明文密码 |
| 修改密码 / 重置密码 | `PUT /users/{username}` | 传新密码 |
| 修改姓名 / 邮箱 | `PUT /users/{username}` | 传 name / email |
| 停用 / 离职 | `DELETE /users/{username}` | 删除影子账号，立即失去 IM 登录 |
| 恢复在职 | `POST /users`（重建） | 重新同步影子账号 |
| 建通讯录关系 | `POST /users/{a}/roster` + `POST /users/{b}/roster` | 双向各调一次，`subscriptionType=3` |

> ⚠️ 关键约束：
> - **禁止直连 Openfire 数据库**，一切账号操作走 REST API。
> - `username` 必须全小写、无空格（Openfire 认证会 `toLowerCase()` 后精确查库，大写/空格会导致「密码对却登录失败」）。
> - 同步失败不阻塞平台主流程，告警 + 重试即可。

## 五、前端 IM 连接参数

| 项 | 值 |
|---|---|
| 凭证接口 | `GET /api/v1/im/credentials`（带 Web JWT） |
| 返回字段 | `jid` / `username` / `password` / `domain` / `http_bind_path` |
| 连接方式 | converse.js，BOSH 通道（`http_bind_path` = `/http-bind/`） |
| 域 | `xmpp.collab.local` |

前端登录流程：`GET /im/credentials` 取回 jid + 密码 → converse 用 BOSH 连 `/http-bind/` → Openfire JDBC 认证。

## 六、主机访问说明

| 场景 | 地址 |
|---|---|
| 本机（浏览器） | `http://localhost:8080`（HTTP）或 `https://localhost:8443`（HTTPS） |
| 局域网其他机器 / 手机 | `https://192.168.31.19:8443`（当前 IP） |

> ⚠️ Mac 局域网 IP 会随 WiFi 切换变化，换网络后重新查：`ipconfig getifaddr en0`。
> 手机跨机必须用 HTTPS（浏览器音视频权限只在安全上下文可用）。
