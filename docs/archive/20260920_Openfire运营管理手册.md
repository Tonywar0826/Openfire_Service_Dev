# Openfire IM 运营管理手册

> 版本：v1.1 · 2026-09-21 · 适用：协作平台 Openfire IM 服务（Openfire 5.1.2 + 独立 postgres 实例）
> 读者：Openfire 系统管理员（测试 / 部署 / 运维）
> 标准依据：**ITIL 4（IT 服务管理最佳实践）+ ISO/IEC 20000-1（IT 服务管理体系）**
> 说明：本手册按 ITIL 实践域组织（服务概览 → 配置管理 → 监控事件 → 问题 → 变更 → 部署 → 容量 → 连续性 → 安全 → 日常 SOP → 排障速查），是 Openfire IM 日常运营的唯一权威依据，取代旧的《Openfire 服务运营管理》（原文件保留供回溯）。
> 安全红线：所有密码 / 密钥 / 连接串一律 `<占位符>`，不写明文。

## 2. 监控与事件管理

### 2.1 监控体系（实际部署，非规划）

| 组件 | 端口 | 用途 |
|---|---|---|
| Prometheus | 19093 | 指标时序库（`--web.enable-lifecycle` 已开） |
| Grafana | 13000 | 可视化看板（admin/admin） |
| cadvisor | 18080 | 容器指标 |
| postgres-exporter | 19187 | 平台库指标 |
| openfire-db-exporter | 19188 | Openfire 库指标 |
| redis-exporter | 19121 | Redis 指标 |
| pushgateway | 19091 | 探针指标暂存 |
| BOSH 探针 | cron（每 2 分钟） | IM 登录黑盒探测 |

- 看板「Openfire IM 服务监控」uid `openfire-im-monitoring`，数据源 uid `afysmv31mxx4wf`，provisioning 自动加载（删卷可自动恢复）。
- **注意**：cadvisor 在 Docker Desktop Mac 上无 `container_network_*` 网络指标（用磁盘 IO 替代）；无 ES/Kibana/Alertmanager/fluent-bit/node_exporter（旧文档里的规划项，未部署）。

### 2.2 关键监控指标与告警阈值

| 类别 | 指标 | 阈值 |
|---|---|---|
| IM 探针 | `im_login_success` / `im_login_latency_seconds` | 连续 2 次失败 P0 |
| 容器内存 | `container_memory_usage_bytes` | > limit 85% P1 |
| 容器 CPU | `container_cpu_usage_seconds_total` | 持续 >80% P2 |
| 在线会话 | REST API `/sessions` | 5 分钟突降 >50% P1 |
| SASL 认证 | 日志 `grep SASLAuthentication` | 失败率 >10%/5min P1 |
| DB 连接 | `pg_stat_database_numbackends` | 连接耗尽 P1 |
| 离线消息 | `ofOffline` 行数 | 积压持续增长 P2 |
| 磁盘 | `node_filesystem_avail_bytes` | 剩余 <20% P1 |

### 2.3 事件分级

| 级别 | 定义 | 示例 |
|---|---|---|
| P0 紧急 | 服务不可用 / 数据丢失 | Openfire down、登录全失败、消息全丢 |
| P1 重要 | 功能受损、影响部分用户 | 单账号认证失败、同步持续失败 |
| P2 提醒 | 隐患、性能劣化 | 内存偏高、慢查询、离线消息积压 |

### 2.4 事件排查顺序（自下而上五层）

连接 → 认证 → 会话 → 消息 → 媒体。先看「连没连上」，再看「认没认证」，逐层递进，别跳层乱查。

## 4. 变更管理

### 4.1 变更流程

1. 评估影响（是否动 Openfire 配置 / 是否需重启 / 是否影响在线用户）
2. 记录变更（本文档 §11 变更日志）
3. 备份（改配置前先备份 `openfire.xml` / `ofProperty`）
4. 实施 + 验证
5. 回滚预案（记录「改了什么、怎么回滚」）

### 4.2 插件安装 / 升级（monitoring 插件为范例）

```bash
# 1) 下载（GitHub release，走代理 + 断点续传；igniterealtime.org 直连会超时）
curl -sSL -C - -x http://127.0.0.1:7890 -o monitoring.jar \
  "https://github.com/igniterealtime/openfire-monitoring-plugin/releases/download/v2.8.0/monitoring.jar"

# 2) 校验 jar 完整性
unzip -t monitoring.jar

# 3) 装入容器并重启（自动安装）
docker cp monitoring.jar collab-openfire:/opt/openfire/plugins/monitoring.jar
docker restart collab-openfire

# 4) 确认加载成功（日志出现 Successfully loaded plugin，无 Exception）
docker logs collab-openfire | grep -iE "Successfully loaded plugin|Exception.*monitoring"
```

**⚠️ 版本兼容性坑**：monitoring 插件 v2.2.0/2.5.0 调旧 API `JiveGlobals.getHomeDirectory()`（报 NoSuchMethodError）、v2.6.1 在 4.9.2 下运行时崩溃（`IncompatibleClassChangeError`，BUG-041）；**当前 Openfire 5.1.2 用 v2.8.0（minServerVersion 5.1.0），已装回并验证（schema 8→10 自动升级、历史数据保留）**。

### 4.3 开启消息归档

```bash
docker exec collab-openfire-db psql -U openfire -d openfire -c \
"INSERT INTO ofProperty(name,propValue) VALUES
 ('conversation.messageArchiving','true'),
 ('conversation.metadataArchiving','true'),
 ('conversation.roomArchiving','true'),
 ('conversation.roomArchivingStanzas','true')
 ON CONFLICT(name) DO UPDATE SET propValue='true';"
docker restart collab-openfire
```

验证：发一条消息后 `SELECT COUNT(*) FROM ofmessagearchive;` 增长即成功。

### 4.4 回滚

- 插件回滚：删除 `plugins/monitoring.jar` → 重启（回到无归档状态）。
- 配置回滚：`DELETE FROM ofProperty WHERE name LIKE 'conversation.%'` → 重启。

## 7. 安全运营

- 管理台仅本机（`127.0.0.1:19090:9090`），不对局域网开放。
- 明文 XMPP 端口（c2s 5222 / BOSH 7070 / FTP 7777）已关闭，仅 TLS。
- SASL 用 SCRAM-SHA-1；ofUser 密码存 `encryptedPassword`（Blowfish 可逆）；Redis 已加 requirepass。
- **⚠️ 遗留**：openfire 库 25432 与主库 5432 端口未绑 127.0.0.1，暴露局域网——生产上线前必须收敛。

## 9. 排障速查（附录）

### 9.1 常用命令

```bash
# 数据库直查（最全，33 张表）
docker exec collab-openfire-db psql -U openfire -d openfire

# 在线会话（在线状态在 Openfire 内存，不在 ofPresence 表）
curl -u "admin:<ADMIN_PWD>" http://localhost:19090/plugins/restapi/v1/sessions

# 认证失败（排障关键）
docker logs collab-openfire --since 1h | grep -i "SASL\|not-authorized"

# 会话假死 / 僵尸会话
docker logs collab-openfire | grep "Closing idle session"
docker logs collab-openfire | grep -iE "complete.*not.*consumed|IllegalStateException"

# 插件加载错误
docker logs collab-openfire | grep -iE "Exception.*plugin|NoSuchMethodError"
```

### 9.2 常用 SQL

```sql
-- 用户列表
SELECT username, name, email FROM ofUser ORDER BY username;
-- 某用户好友（roster）
SELECT jid, nick, sub FROM ofRoster WHERE username = 'yuzhouxiang';
-- 离线消息积压
SELECT count(*) FROM ofOffline;
-- 消息归档量
SELECT count(*) FROM ofMessageArchive;
-- 群聊房间
SELECT name, subject FROM ofMucRoom;
-- 关键系统配置
SELECT name, propvalue FROM ofProperty WHERE name LIKE 'conversation.%' OR name LIKE 'plugin.restapi%';
-- 各表数据量（判断增长）
SELECT relname, n_live_tup FROM pg_stat_user_tables ORDER BY n_live_tup DESC;
```

## 10. 告警规则汇总

| 级别 | 触发条件 | 通知 |
|---|---|---|
| P0 紧急 | IM 探针连续 2 次失败 / Openfire 容器 down / 库不可达 | 立即 |
| P1 重要 | 在线用户 5min 突降 >50% / SASL 失败率 >10% / 内存 >85% / 同步失败持续 | 5 分钟内 |
| P2 提醒 | 堆 >85% / 磁盘 >80% / 慢查询 / 离线消息积压 | 聚合 |
