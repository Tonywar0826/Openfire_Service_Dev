## 一、设计定位

部署管理平台是一个**网页形式**的管理后台，核心诉求是**零代码、可视化、一键操作**——使用者全程点按钮完成「部署 / 扩展 / 回退 / 备份 / 恢复 / 监控」，不写任何命令、不碰代码。

风格：**企业级管理后台**，Teams 紫色调，与协作平台视觉统一。

## 四、各页面设计

### 4.1 概览（首页仪表盘）

**布局**（从上到下）：

1. **4 张状态卡**：Openfire 实例数 / 在线用户数 / 数据库状态 / 今日告警数
2. **当前拓扑图**：nginx → Openfire 集群 → Patroni 数据库 → coturn，节点带健康状态灯
3. **最近告警列表**：告警等级 + 描述 + 时间

**目的**：用户打开平台，一眼看清「整体健不健康」。

### 4.2 目标服务器

- **目标服务器列表**：每行显示服务器名 / IP / 连接方式（Agent / SSH / Docker 远程端口）/ 连接状态灯
- 「添加服务器」按钮 → 弹窗三步：① 填名称/IP → ② 选连接方式 → ③ 填对应凭据（Agent 地址 / SSH 账号密钥 / Docker TLS 证书）
- 连接方式三选一（可插拔）：
  - **Agent 模式（推荐）**：填 Agent 地址 + 令牌，权限最小、不碰客户 SSH/密码
  - **SSH 直连**：填 IP + 账号 + 密钥/密码
  - **Docker 远程端口**：填 IP:2376 + TLS 证书
- 每行「测试连接」按钮，验证能连通
- 部署/扩展/备份时，先选「目标服务器」，再操作

**目的**：实施人员先登记客户服务器（选好连接方式），之后所有一键操作都作用在这台服务器上。

### 4.3 部署（向导式）

**4 步向导**：选择规模 → 填写参数 → 确认部署 → 结果（配置同步 + 自检）

- 第 1 步：规模卡片（small/medium/large/**自定义**），点选
  - **自定义**：展开输入框，自由指定 Openfire 实例数、coturn 实例数、数据库方案（单实例/主从/Patroni）
- 第 2 步：参数表单（**域名 / admin 密码 / 数据库密码 / 局域网 IP，4 个必填**）+ 可选 coturn（端口/用户/密码，默认与协作平台一致，折叠可展开、每项带提示说明）
- 第 3 步：确认摘要 + 「一键部署」按钮
- 第 4 步：结果页 = 部署概览 + **② 配置同步清单**（10 项：配置名称 + 概要说明 + 状态灯）+ **③ 自检清单**（4 层：容器→服务→功能→Bug 回归，逐项状态灯 + 汇总计数）

**原则**：像「装软件」一样，点「下一步」逐步走，参数有默认值、可留空；部署后逐项校验、状态一眼可见。

### 4.4 拓扑与扩展

- 可视化拓扑图（同概览的拓扑，但可交互）
- 「扩展」按钮 → 弹窗选目标实例数 → 自动加实例
- 扩展过程实时显示进度（新实例状态从「启动中」→「健康」）

### 4.5 回退

- **版本快照列表**：版本号 / 时间 / 操作说明（每次部署/扩展/升级自动记录）
- 每行一个「回退」按钮 → 二次确认弹窗 → 一键还原
- 回退后列表显示当前生效版本

### 4.6 备份

- **备份列表**：备份时间 / 类型（自动/手动）/ 存储位置（本地/异地）/ 大小
- 顶部：「立即备份」按钮 + 定时策略设置（每天几点、保留几份）
- 每行「恢复」按钮 → 二次确认 → 一键恢复

### 4.7 监控

- Grafana 风格看板：资源折线图（CPU/内存/磁盘）+ 业务指标卡（在线数/消息量）
- 告警列表（阈值告警、实例宕机、备份失败）
- 复用协作平台已部署的 Prometheus + Grafana

### 4.8 设置

- 环境参数：端口 / 密码 / 域名 / 规模档位 / 镜像版本
- 修改保存后，下次部署/扩展使用新参数

## 五、设计原则（贯穿每个页面）

1. **零代码**：所有操作都是「点按钮」，绝不出现命令行、SQL、脚本输入框
2. **可视化**：拓扑图、状态卡、看板、进度条，状态一眼可见
3. **防误操作**：破坏性操作（回退 / 删除 / 恢复）都有二次确认弹窗
4. **有默认值**：参数尽量有默认值，减少填写负担
5. **配色统一**：主色 `#5b5fc7`（Teams 紫），成功绿 `#22c55e`、告警黄 `#f59e0b`、危险红 `#ef4444`
