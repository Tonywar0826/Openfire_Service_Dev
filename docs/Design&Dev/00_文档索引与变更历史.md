## 五、术语表

| 术语 | 全称 | 说明 |
|---|---|---|
| IM | Instant Messaging | 即时通讯 |
| XMPP | Extensible Messaging and Presence Protocol | 开放即时通讯协议，Openfire 实现它 |
| BOSH | Bidirectional-streams Over Synchronous HTTP | 浏览器长轮询连 XMPP 的方式，converse.js 用它 |
| MUC | Multi-User Chat | 群聊 |
| JID | Jabber ID | XMPP 账号标识，形如 `用户名@域名` |
| roster | — | 通讯录/好友列表（ofRoster 表） |
| SCRAM-SHA-1 | Salted Challenge Response Auth Mechanism | 一种不传明文密码的认证方式 |
| TURN/STUN | — | 音视频媒体中转协议（coturn 实现） |
| 影子账号 | — | Openfire 侧跟随平台账号同步出来的账号副本 |
| 主数据 | — | 权威数据源，指协作平台的账号数据 |
