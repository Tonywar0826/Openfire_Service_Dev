## 1. 测试概述

### 1.1 测试目的
验证 Openfire IM 服务端的**服务能力**（账号同步、凭证签发、REST API）与**业务功能**（登录、单聊、群聊、通讯录、音视频、附件、账号生命周期）是否满足 SRS 定义的功能需求（FR）与验收标准（AC），并复现/定位已知缺陷（F-05 离线消息）。

### 1.2 测试范围

| 类别 | 在范围内 | 不在范围内 |
|---|---|---|
| 服务验证 | 账号同步（建号/改密/禁用/删除/恢复）、凭证签发、REST API | 平台自身业务（非 IM） |
| 功能测试 | 登录、单聊（在线/离线）、群聊、通讯录、音视频信令、附件、账号生命周期 | 多方会议/录制/离线推送（Openfire 社区版无此能力） |

### 1.3 参考文档

| 文档 | 用途 |
|---|---|
| 01_需求规格说明书_SRS.md | 需求追溯（FR/AC/NFR） |
| 02_概要设计_HLD.md | 模块与数据流理解 |
| 03_接口设计_API规格.md | 接口契约、数据模型 |
| 04_安全设计.md | 安全项验证 |

### 1.4 术语

| 术语 | 说明 |
|---|---|
| PASS / FAIL | 用例通过 / 失败 |
| N/A | 不适用（环境/前置条件不满足） |
| 缺陷等级 P0/P1/P2 | 见 §3.4 |

## 3. 测试策略

### 3.1 测试类型

| 类型 | 说明 |
|---|---|
| 功能测试 | 验证正常业务路径（正面用例） |
| 边界测试 | 验证边界输入（重复建号、错误格式） |
| 异常测试 | 验证异常输入/状态（错误密码、不存在账号、认证失败） |

### 3.2 测试方法
**黑盒测试**：通过对外接口（REST API、BOSH、数据库查询）验证行为，不关注内部实现。

### 3.3 通过/失败判定标准

| 判定 | 条件 |
|---|---|
| **PASS** | 所有步骤的「预期」全部满足 |
| **FAIL** | 任一步骤的「预期」不满足（记录实际现象，作为缺陷） |
| **N/A** | 前置条件不满足或环境不支持（注明原因，不计入通过率） |

### 3.4 缺陷等级定义

| 等级 | 定义 | 示例 |
|---|---|---|
| P0 | 核心功能不可用，阻塞上线 | 账号同步失败、登录失败、离职仍可登 IM |
| P1 | 主要功能缺陷，影响使用 | 离线消息丢失、群聊建房失败 |
| P2 | 次要缺陷，可容忍 | 边界异常、提示不友好 |
