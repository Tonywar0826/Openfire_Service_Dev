### 2.1 openfire.xml 密码加密机制（开发人员必读）

- 密码用 `Blowfish(key).encrypt(password)` 加密，存 `<password encrypted="true">密文</password>`。
- 密钥用 `AesEncryptor().encrypt(key)` 加密，存 `security.xml` 的 `<key><current>密文</current>`。
- Openfire 启动读密码时：`getCurrentKey()`（AES 解 current）→ `new Blowfish(key).decrypt(密文)` 还原。
- ⚠️ 两个坑：① `docker cp` 覆盖 security.xml 会把属主改成宿主机 UID，Openfire 无法写入 → 解密失败 → `FATAL: password authentication failed`，必须 `docker exec -u 0 chown openfire:openfire conf/security.xml`；② security.xml 在 `openfire_conf` 卷（不在 git），卷丢失 = 密钥丢失 = 密文解不开，需连同 conf 卷一起备份。

## 3. 授权与账号生命周期

- **权限统一在平台**：谁能建群、拉人、看通讯录由平台 ACL 决定；Openfire MUC 权限（owner/admin/member）由平台发起时映射。
- **禁用/删除同步**（✅ 已实现）：停用（status=0）→ `DELETE /users` 删影子账号、保留缓存密码（便于恢复）；离职（status=2）→ 删影子账号 + 清缓存密码；恢复在职（status=1）→ 从缓存重建影子账号。**离职/停用用户立即失去 IM 登录能力**（BOSH 返回 `<not-authorized/>`）。
- **域隔离**：`xmpp.collab.local` 域内认证，禁止跨域/域外账号注册（Openfire 默认关闭自注册，需确认）。

## 4. 攻击面收敛

| 威胁 | 防护 |
|---|---|
| 管理台弱密码 | 强密码 + 限制来源 IP（已绑 127.0.0.1） |
| 暴力破解 | BOSH/c2s 认证失败限速（`security.` 属性）；管理台 nginx limit_req |
| BOSH 资源耗尽 | 限制单连接会话数、长轮询超时（`xmpp.httpbind.client.idle` 已调 1800） |
| 明文密码泄露 | ofUser encryptedPassword、Redis requirepass、openfire.xml 加密、日志脱敏 |

## 5. 审计与合规

- **消息归档**：Openfire Monitoring 插件开消息归档（ofMessageArchive），满足审计/合规。
- **操作留痕**：平台侧登录/授权/建号/改密/禁用/删除入平台操作日志（已实现）；Openfire 侧开启 admin 审计日志（ofSecurityAuditLog）。
- **日志安全**：结构化 JSON 集中采集，脱敏密码字段（禁止日志打印明文密码）。
